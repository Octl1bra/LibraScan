## 1. 产品概述

LibraScan 是一款极简的 iPhone 扫码工具，支持扫描二维码（QR Code）和常见一维条形码（EAN、Code 128 等），并自动保存扫码记录，方便用户随时回看、复制和分享历史结果。

**核心理念：打开即扫、扫完即存、随时可查。** 不做账号体系、不做云同步、不做广告，所有数据保存在本机。

## 2. 目标用户与场景

- **日常用户**：扫描海报 / 名片 / 商品上的二维码，打开链接或复制内容。
- **比价 / 记录场景**：扫描商品条形码，保留编码记录以便后续查询。
- **整理场景**：连续扫描多个码（如快递单、库存标签），事后在历史记录中统一查看。

## 3. 功能需求

应用为底部双 Tab 结构：

```
┌──────────────────────────────┐
│                              │
│        相机取景区域           │
│     （扫描框 + 实时识别）      │
│                              │
│   [手电筒]                    │
├──────────────────────────────┤
│    📷 扫一扫    │   🕘 记录    │
└──────────────────────────────┘
```

### 3.1 Tab 1：扫一扫（Scan）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| F1.1 | 进入 Tab 自动启动相机预览，居中显示扫描参考框 | P0 |
| F1.2 | 支持识别 QR Code 及常见一维码（详见 3.3 码制范围） | P0 |
| F1.3 | 识别成功后：震动反馈 + 底部弹出结果卡片（不打断取景） | P0 |
| F1.4 | 结果卡片展示：内容文本、码制类型、操作按钮（复制 / 打开链接 / 分享） | P0 |
| F1.5 | 识别成功自动写入扫码记录 | P0 |
| F1.6 | 同一内容 2 秒内重复识别只记录一次（防连拍重复） | P0 |
| F1.7 | 手电筒开关按钮（弱光环境） | P1 |
| F1.10 | 双指捏合变焦（远处 / 小尺寸码），显示当前倍率 | P1 |
| F1.8 | 相机权限未授权时显示引导页，提供跳转「设置」按钮 | P0 |
| F1.9 | 切换到「记录」Tab 或 App 退到后台时暂停相机会话，回来时恢复 | P0 |

**结果卡片操作逻辑：**

- 内容为 URL → 主按钮为「打开链接」（Safari 打开），次按钮「复制」「分享」。
- 内容为纯文本 / 编码 → 主按钮为「复制」，次按钮「分享」。
- 卡片可手动下滑关闭；关闭后继续扫描下一个码。

### 3.2 Tab 2：记录（History）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| F2.1 | 按时间倒序展示扫码记录列表 | P0 |
| F2.2 | 每条记录显示：内容摘要（最多 2 行）、码制类型标签、扫码时间 | P0 |
| F2.3 | 点击记录进入详情：完整内容 + 复制 / 打开链接 / 分享 | P0 |
| F2.4 | 左滑删除单条记录 | P0 |
| F2.5 | 「清空全部」入口（二次确认弹窗） | P1 |
| F2.6 | 记录为空时显示空态插画与文案「还没有扫码记录」 | P1 |
| F2.7 | 顶部搜索框，按内容关键字过滤 | P2 |

### 3.3 支持的码制范围（v1.0）

- **二维码**：QR Code、Data Matrix、Aztec、PDF417
- **一维码**：EAN-13、EAN-8、UPC-E、Code 39、Code 93、Code 128、ITF-14、Codabar

### 3.4 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 冷启动到相机可用 ≤ 1.5s；正常光线下识别耗时 ≤ 0.5s |
| 隐私 | 所有记录仅存本机；相机画面不上传、不存储；无第三方 SDK、无埋点 |
| 权限 | 仅申请相机权限，并提供清晰的用途说明文案 |
| 无障碍 | 支持 Dynamic Type；关键按钮有 VoiceOver 标签 |
| 本地化 | v1.0 简体中文 + 英文 |

## 4. 不做什么（v1.0 明确范围外）

- 生成二维码
- 从相册图片识别码（v1.1 候选）
- iCloud 同步 / 多设备
- 账号、登录、云端任何能力
- 连续批量扫码模式（v1.1 候选）

## 5. 成功指标（MVP）

- 用户从启动到完成一次扫码 ≤ 5 秒
- 扫码成功后记录写入成功率 100%
- 崩溃率 < 0.1%
